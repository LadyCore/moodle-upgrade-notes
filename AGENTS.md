# Documentation boundaries

- This repository documents a generic, reproducible Moodle upgrade, not its originating deployments.
- Follow docs/privacidad.md for every file, filename, commit and proposed publication.
- The intended repository is public. The publisher's personal identity need not
  be hidden; protect the originating institution and its operational information.
  Exclude institutional author emails and identifying commit or issue metadata.
- Never include real platform owners, personal or administrative usernames, emails,
  institutions, IP addresses, installation domains, hostnames, VM names, course names
  or personal filesystem paths.
- Do not copy raw operational logs, screenshots, configuration files, credentials,
  databases, course backups or moodledata into this repository, even temporarily.
- Keep technical provenance that is necessary for reproduction, including Linux
  distribution/version and verified software versions. Reference OS is CentOS Stream 9 Minimal.
- Use explicit placeholders for environment-specific values in procedures.
- Keep proposed steps, observed executions, functional tests and production approval distinct.
- Preserve public technical citations and plugin-author attribution without identifying the platform owner.
- Never publish remotely, change repository visibility, create identities or alter
  Git author information without appropriate user authorization.
